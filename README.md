# OJTHub

**Geofenced OJT Attendance, AI-Assisted Reporting, and Customizable Management PWA**

- **Live Production Application:** [https://ojthub.onrender.com](https://ojthub.onrender.com)
- **Presentation & Defense Playbook:** See [`PRESENTATION_GUIDE.md`](./PRESENTATION_GUIDE.md) for the 4-minute presentation script, demo accounts, and panel Q&A cheat sheet.

---

## Key Features
- **Geofenced Precision Attendance:** Haversine GPS perimeter checking, company name & address display, early time-out warnings, and duplicate punch prevention.
- **Interactive PDF Generation:** DTR and Accomplishment Logbook PDF previews directly in-browser before downloading.
- **Unified Daily Journal:** One-click shift synchronization, inline editing, voice dictation (Web Speech API), and natural human-English AI Polish.
- **Dynamic Curriculum Milestones:** Adaptive academic milestones (243h, 300h, 486h, 500h, 600h + custom hour) with automatic Midterm and Final labeling.
- **Student Submission & Teacher Evaluation:** Students can submit milestone activity reports to their teacher for review, while retaining full self-sufficiency (no teacher required to export or use the app).
- **Teacher / Supervisor Portal:** 6-character linking code (`ICCT-2026`), trainee live shift tracking, excuse slips/manual adjustments, and milestone review.
- **Progressive Web App (PWA):** Installable on mobile and desktop with offline support and local queue synchronization.
